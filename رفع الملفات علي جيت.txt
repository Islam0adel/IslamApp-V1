الرفع بالقوة (Force Push):
عشان نتخطى رفض جيت هب ونمسح النسخة القديمة اللي مسببة المشاكل:

ـــــــــــــــــــــــــــــــــــــــــــــــــــــــــــــــــــــــــــــ

الإضافة والرفع "بالقوة"
هنضيف كل الملفات حتى لو الجيت بيحاول يتجاهلها (عشان نضمن إن فولدر الـ web و الـ build يترفعوا):

Bash
# 1. إضافة كل شيء في المشروع
git add .
ـــــــــــــــــــــــــــــــــــــــــــــــــــــــــــــــــــــــــــــــــــ
# 2. عمل الـ Commit
git commit -m "Fix: Force upload all missing web and backend files"
ــــــــــــــــــــــــــــــــــــــــــــــــــــــــــــــــــــــــــــــــــ
# 3. الرفع النهائي
git push origin main --force
